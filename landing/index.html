Политика конфиденциальности

Дата вступления в силу: 19 апреля 2026 г.

1. Какие данные мы собираем

  • Данные учётной записи: email, имя, хэш пароля, токены OAuth.
  • Данные мессенджеров: идентификаторы аккаунтов Telegram / ВКонтакте, зашифрованные сессионные токены.
  • Данные переписки: входящие сообщения клиентов, обрабатываемые агентом, и ответы агента.
  • База знаний: документы, QA-пары, URL, загружаемые пользователем.
  • Технические данные: IP-адрес, User-Agent, логи запросов (хранятся не более 90 дней).

2. Как мы используем данные

  • Для предоставления и улучшения Сервиса.
  • Для генерации ответов AI-агентами (данные передаются в OpenAI / Cohere / Groq).
  • Для векторного поиска (Pinecone) по базе знаний пользователя.
  • Для отправки push-уведомлений о горячих лидах (Firebase).
  • Мы не продаём и не передаём ваши данные третьим лицам в коммерческих целях.

3. Хранение и безопасность

  • Сессионные токены мессенджеров хранятся в зашифрованном виде (AES-256).
  • Все данные в базе данных PostgreSQL на сервере в России.
  • Доступ к данным возможен только по HTTPS.
  • Мы применяем JWT-аутентификацию и ограничение частоты запросов (rate limiting).

4. Передача данных третьим сторонам

Для работы Сервиса данные могут передаваться следующим провайдерам:

  • OpenAI / Groq — генерация ответов AI (тексты сообщений).
  • Cohere — создание векторных эмбеддингов (тексты из базы знаний).
  • Pinecone — хранение и поиск векторов.
  • Google — OAuth, Sheets, Calendar (данные, необходимые для конкретной интеграции).
  • Firebase (Google) — push-уведомления (device token).
